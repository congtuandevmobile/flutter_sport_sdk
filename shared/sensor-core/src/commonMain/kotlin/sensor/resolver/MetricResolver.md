# MetricResolver.kt

**Path:** `.../sensor/resolver/MetricResolver.kt` · **Layer:** resolver

Chooses ONE source per metric (not per workout), never averaging or summing. A source is a candidate while connected, fresh (`staleAfterMs`, 5 s) and recovered (`recoveryMinSamples` 2 over `recoveryMinMs` 1 s since a (re)connect or a stale spell). Choice: the user's preference while it is a candidate, else the candidate of the best RANK for the metric (`SourcePolicy`, from `setCapabilities`), else among equals the source already chosen (two equally good sources never alternate), else the one seen first. A better ranked source that becomes healthy takes over once. A source is `(sourceId, epoch)`: an event of an older epoch is dropped and a newer epoch forgets the source's values; the SAME epoch coming back from a disconnect also forgets them (an adapter that forgot to bump the epoch cannot reuse a dead link's values). `onConnection`, `onReading`, `setPreferred`, `setCapabilities`, `forget`, `resolve(nowMs)`, `reset`. A value of 0 is a measurement. One monotonic clock; not thread-safe.
